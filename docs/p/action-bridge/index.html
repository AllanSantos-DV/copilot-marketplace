action-bridge

v1.3.0

O action-bridge conecta o Copilot ao Action no Windows. Peça para encontrar uma reunião em andamento, iniciar uma gravação por projeto ou consultar o que já foi discutido. O Action entrega as transcrições; o agente da sua IDE usa esse contexto para publicar insights no painel.

⌁ copilot plugin install action-bridge@copilot-marketplace
código↗

  • Entre quando precisar

    Encontre a reunião pelo nome e receba também as falas anteriores, sem copiar código do painel.

  • Contexto por projeto

    Escolha um projeto existente ou crie pelo nome. Consulte reuniões salvas e a memória compartilhada.

  • Áudio sob seu controle

    Transcreva com o Vox local e, se quiser, guarde microfone e áudio do Windows em arquivos separados.

#A reunião já começou? Entre nela

Abra o agente na pasta do projeto e peça para localizar a reunião. O MCP lista as sessões do painel web /live e as iniciadas pelo próprio MCP, com filtro por título ou projeto. Você não precisa informar um project_id para descobrir o que está acontecendo.

  1. Encontre a sessão

    Diga o nome da reunião ou peça a lista. Se houver mais de uma correspondência, escolha a que quer acompanhar.

  2. Entre com contexto

    O agente recebe as falas anteriores e pode consultar o restante do histórico antes de acompanhar os próximos lotes.

  3. Acompanhe e saia pela conversa

    Os insights publicados aparecem no painel. Peça para sair quando terminar; sair do acompanhamento mantém a gravação ativa.

Exemplo de pedido ao agente:

Encontre a reunião Alpha.
Entre nela, leia o contexto
e publique insights concisos
enquanto eu acompanho.
i

Mais de um agente pode entrar na mesma reunião. Cada um acompanha as transcrições no seu ritmo; a saída de um não desconecta os outros.

#Comece uma reunião pelo agente

Peça a lista de projetos e escolha um. Se ele ainda não existir, informe um novo nome para criá-lo. Ao iniciar a gravação pelo MCP, o agente já recebe o vínculo para acompanhar a reunião.

Liste meus projetos.
Quero gravar uma reunião sobre
Alpha e que você participe.
Salve também o áudio em arquivo.

Você também pode começar pelo painel web /live do Action e convidar o agente depois. As gravações da interface desktop antiga não entram nesse acompanhamento. Para finalizar a captura, peça explicitamente encerrar a gravação. Esse comando é diferente de sair da reunião como agente.

#Retome o que o projeto já discutiu

As reuniões salvas continuam disponíveis para listar, buscar e ler a transcrição. Peça ao agente para recuperar decisões anteriores, comparar discussões ou organizar os próximos passos.

  • Arquivo da reunião: transcrições e os áudios que você optar por salvar ficam em disco.
  • Projetos e memória: o Action se integra ao daemon de memória compartilhado pelos seus plugins na máquina.
  • Contexto da IDE: o agente pode combinar a reunião com os arquivos e as ferramentas de memória disponíveis na própria sessão.

#Escolha onde o áudio é processado

A transcrição usa o Vox local por padrão, aproveitando o daemon da máquina. A opção de guardar áudio salva mic.wav e system.wav separadamente para consulta ou processamento posterior.

!

Groq Whisper envia áudio à nuvem. Só é usado após habilitação explícita e consentimento. Configure GROQ_API_KEY ou GROQ_API_KEYS; com várias chaves, o Action pode alternar quando a cota diária for atingida.

O modelo que produz os insights é o da sua IDE. As transcrições entregues ao agente seguem a configuração e o provedor desse cliente, mesmo quando a transcrição do áudio é local.

#Como o agente continua acompanhando

O Action entrega um lote de transcrições por chamada. O agente lê o lote, decide se há algo útil para comentar, publica o insight e chama a próxima leitura. Em silêncio, a espera pode retornar sem novas falas.

i

Manter esse ciclo depende do cliente da IDE. Conectar o MCP não garante acompanhamento contínuo em todo host. O fluxo direto foi validado no Claude Code CLI com falas sintéticas. O Codex tem integração própria, descrita abaixo; a continuidade no Copilot e no Cursor ainda precisa de validação.

Mantenha a sessão aberta e confira se o agente continua consultando a reunião. Os adaptadores experimentais que abrem sessões auxiliares não controlam automaticamente o chat já aberto na IDE.

#Use o Action na conversa do Codex

O pacote do Action inclui o plugin action-meeting para o app e a CLI do Codex. Ele conecta o MCP à mesma conversa em que você trabalha no projeto. Tenha o Codex CLI 0.158.0 ou posterior instalado e autenticado; no PowerShell, dentro da pasta extraída do Action, execute:

.\Codex\setup.ps1

O modo padrão é Plugin. Para a extensão Codex na IDE, que ainda não aceita plugins, execute o mesmo setup com -Mode Skills. Esse modo instala as quatro skills e os hooks no perfil pessoal. Escolha um modo por perfil para evitar duplicação.

  1. Abra uma nova sessão na pasta do projeto

    Confira o servidor em /mcp e os comandos em /skills. Em /hooks, revise e confie os hooks do Action antes de usá-los. Hooks alterados exigem nova revisão.

  2. Peça para participar ou gravar

    Use $action-join revisão Alpha para entrar ou $action-record Alpha guardar áudio para iniciar. Também pode pedir em linguagem comum; o agente descobre a reunião e o projeto pelo MCP.

  3. Encerre o acompanhamento quando quiser

    Use $action-leave para sair ou $action-stop para finalizar a gravação. Esc/Parar interrompe a tarefa e desarma a retomada; depois, peça explicitamente para retomar ou liberar o vínculo.

i

O hook Stop pede a próxima leitura na mesma sessão quando o agente tenta finalizar com vínculo ativo. A retomada depende de hooks habilitados e confiados, sessão aberta e progresso nas leituras. Na extensão da IDE, confira se a versão do host executa esses hooks.

Validado no Codex CLI interativo 0.158.0: descoberta pelo nome, leitura do histórico e três insights com referências. Após 35 segundos de silêncio, o hook retomou a mesma sessão. Nesse ensaio, a saída por mensagem normal foi confirmada em 5,26 segundos e manteve a gravação ativa.

O ensaio usou transcrições sintéticas, sem captura de áudio; não valida a interface gráfica do app ou da extensão. Os hooks foram revisados e habilitados temporariamente para o teste. Na sua instalação, revise e confie neles em /hooks. O modelo e o provedor continuam sendo os configurados no seu Codex.

#Instalação e atualização do Action

Se o Action ainda não estiver instalado, a ponte pode baixar o ZIP assinado da release pública e registrá-lo na máquina. A instalação inicial não usa um Setup.exe separado.

O próprio Action consulta atualizações e pede confirmação para aplicar os pacotes incrementais assinados, com o pacote completo como alternativa. O agente também pode solicitar a atualização; ela não é aplicada durante uma gravação ativa.

i

Os fluxos de descoberta, entrada direta e gravação descritos nesta página requerem Action 1.5.0 ou superior. Atualize também o plugin e reinicie o Copilot para carregar a ponte instalada.

#Instalar

Registre a vitrine uma vez (se ainda não fez):

⌁ copilot plugin marketplace add AllanSantos-DV/copilot-marketplace

Instale o action-bridge:

⌁ copilot plugin install action-bridge@copilot-marketplace

Atualize quando quiser (ou todos com --all):

⌁ copilot plugin update action-bridge
!

Este plugin registra um canvas (painel no app). Depois de instalar ou atualizar, reinicie o app uma vez: o canvas-sync espelha a extensão para ~/.copilot/extensions/ e o app só carrega a versão nova no boot seguinte.

#Perguntas frequentes

Preciso copiar um código para entrar?

Não. Para reuniões do painel /live ou iniciadas pelo MCP, o agente consulta as sessões e usa o identificador retornado para entrar. Ele pode chegar depois do início e ler as transcrições anteriores.

Preciso desta ponte no Claude Code, Codex ou Cursor?

Esta ponte é para o Copilot. O pacote inclui ClaudeCode/setup.ps1, comandos e README para o Claude Code, com PowerShell 5.1/7 e sem Python. Para o Codex, use Codex/setup.ps1: modo Plugin no app/CLI ou Skills na extensão. No Cursor, configure o MCP pelo próprio cliente. A continuidade depende da integração de cada host.

Sair do acompanhamento encerra a gravação?

Não. Sair remove o vínculo daquele agente. Para parar a captura, peça para encerrar a gravação ou use o controle no Action.

Tudo fica na minha máquina?

A captura e a transcrição Vox são locais por padrão. Groq Whisper envia áudio à nuvem quando você o habilita. Transcrições enviadas ao agente seguem o provedor configurado na IDE.

Como atualizar uma instalação do Action 1.4?

Feche as sessões da IDE conectadas ao Action antes de atualizar. Se o atualizador antigo usar o pacote completo e o app continuar na versão 1.4, extraia manualmente o ZIP da release na pasta de instalação do Action.
